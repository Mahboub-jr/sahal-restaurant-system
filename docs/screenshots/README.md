# Screenshots

Four files, each dropped straight into this folder with the exact name
below — the main `README.md` already references them, so nothing else
needs editing once they exist.

| File | Page | Sign in as | Notes |
|---|---|---|---|
| `dashboard.png` | `index.php` | admin | Let it load fully so the revenue chart renders. |
| `place_order.png` | `place_order.php` | admin or waiter | Add 2–3 items to the cart first, so the total/tax/service estimate on the right has real numbers in it. |
| `kitchen.png` | `kitchen.php` | admin | Most useful with at least one order in each of Pending/Preparing/Ready — place a couple of test orders and move them through if the board is empty. |
| `invoice.png` | `invoice.php?id=<any order id>` | admin | Pick an order that has at least one payment recorded, so the payments table isn't empty. |

## How

1. Sign in to the app in a normal browser window (not incognito — some
   browsers block extensions/screenshots there).
2. Resize the window to something reasonable for a README — full width
   but not ultra-wide; ~1400px works well.
3. Full-page screenshot the browser viewport (most browsers: right-click
   → "Capture screenshot" in DevTools, or an extension). A plain window
   screenshot is fine too if a full-page capture isn't handy.
4. Save as PNG, named exactly as in the table above, into this folder.
5. Optional: crop out the browser chrome (address bar etc.) so only the
   app itself shows.

No particular resolution is required — GitHub scales images to fit the
README automatically.
